✦ Claude

เริ่มใช้ Claude วันนี้ — Starter Prompts

เอกสารแจกผู้เข้าร่วม · ลองก๊อปปี้ prompt ไปวางใช้ได้เลย · ไต่ระดับจาก "คุย" ไปสู่ "ทำงานแทน"

LEVEL 1 — Claude.ai · คุยแล้วได้คำตอบที่คิดมาแล้ว

ให้ Claude ช่วยคิด ไม่ใช่แค่ตอบ

เริ่มจากงานที่คุณทำอยู่จริง แล้วปล่อยให้ Claude ถามกลับ

เตรียมประชุมผมมี meeting กับ stakeholder พรุ่งนี้เช้าเรื่อง project ใหม่ ช่วยเตรียมผมหน่อย — ผมควรรู้อะไร และควรถามอะไรบ้าง
สรุปให้สั้นช่วยสรุปอีเมลฉบับนี้เหลือ 3 bullet แล้วร่างคำตอบสั้น ๆ ให้ด้วย: [วางข้อความอีเมลตรงนี้]
ช่วยตัดสินใจผมกำลังเลือกระหว่างตัวเลือก A กับ B [อธิบายสั้น ๆ] ช่วยเปรียบเทียบข้อดีข้อเสีย และถามกลับถ้าต้องการข้อมูลเพิ่ม

เคล็ดลับ: ยิ่งให้บริบทเยอะ คำตอบยิ่งตรง — และถ้า Claude ถามกลับ ให้ตอบ มันจะคิดแทนได้ลึกขึ้น

LEVEL 2 — Artifacts · คุยแล้วได้ชิ้นงานที่แก้ไขได้ทันที

เปลี่ยนคำตอบเป็นชิ้นงาน interactive

ขอให้ Claude สร้าง diagram, dashboard หรือเครื่องมือ แล้วแก้สด ๆ ในหน้าเดียว

สร้าง diagramสร้าง mind map แสดง stakeholders และความสัมพันธ์ในโปรเจกต์นี้ ทำเป็น interactive diagram ที่คลิกดูรายละเอียดได้
แก้ไขสดเพิ่ม node "Risk" และเชื่อมกับ stakeholder ที่เกี่ยวข้อง
ทำเครื่องมือสร้างเครื่องคำนวณ ROI แบบกรอกตัวเลขแล้วเห็นผลทันที ใส่กราฟเปรียบเทียบ 3 สถานการณ์

เคล็ดลับ: ผลลัพธ์ไม่ใช่แค่ข้อความ — เป็นชิ้นงานที่ export เป็น HTML ส่งทีมได้เลย

LEVEL 3 — Cowork · ทำงานบนเครื่องคุณได้เลย

ชี้ไปที่ folder แล้วให้ Claude ลงมือทำ

Cowork อ่านไฟล์จริงในเครื่อง สังเคราะห์ แล้วสร้างไฟล์ผลลัพธ์ให้

สรุปทั้งโฟลเดอร์อ่านไฟล์ทุกอันใน folder โปรเจกต์นี้ (มี spec, meeting notes, test results, รายงานวิจัย) อ่านแล้วสร้าง executive summary 1 หน้า พร้อมส่ง stakeholder พรุ่งนี้
เปลี่ยนฟอร์แมตเอาข้อมูลจากไฟล์ Excel ผลทดสอบ มาทำเป็นสไลด์สรุป 5 หน้า ไฮไลต์เฉพาะประเด็นที่ผู้บริหารต้องตัดสินใจ
ร่างอีเมลจากเอกสารทั้งหมดในโฟลเดอร์ ร่างอีเมลถึง stakeholder ขออนุมัติ go-live พร้อมสรุปความเสี่ยงที่ต้องรู้

เคล็ดลับ: งานที่ปกติใช้เวลาครึ่งวัน Cowork ทำได้ในไม่กี่นาที — โดยคุณไม่ต้องเปิดไฟล์เอง

เริ่มเลยวันนี้ — ฟรี ไม่ต้องใช้บัตรเครดิต

เข้าใช้งานที่ claude.ai

ลองง่าย ๆ 3 ขั้น: ① เอางานที่ทำอยู่มาถาม → ② ขอให้สร้าง diagram/dashboard → ③ ให้ Cowork อ่านโฟลเดอร์เอกสารแล้วสรุป
